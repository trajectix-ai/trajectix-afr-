How it works

Every API call. Every step. Every decision.

Set ANTHROPIC_BASE_URL=http://localhost:8080 and every message your agent sends routes through Trajectix before reaching the Anthropic API.

01

AFR Hash Chain

Every API call is logged to a SHA-256 hash-chained JSONL file. Each entry binds to the previous via chain_hash = SHA-256(prev_hash + content_hash + timestamp). Tamper-evident. Append-only. Forensically admissible.

02

ALE Detection Engine

Five behavioral failure patterns are matched across every message exchange in real time — credential scavenging, logic guessing, privilege escalation, goal-constraint misalignment, and silent reasoning loops.

03

Pipelock Human Gate

When ALE-T004 fires (agent acknowledges a safety constraint then justifies overriding it), the proxy pauses execution and surfaces a terminal decision interface. No request reaches Anthropic until a human approves, denies, or inspects the chain.

04

Gemma 4 / Gemini Forensic Analysis

After the session completes, the full AFR chain is passed to Gemma 4 (default) or Gemini 2.5 Flash (ANALYSIS_MODEL=gemini) for structured root-cause analysis referencing specific chain entries by step ID.

ALE Taxonomy

Five techniques. One framework.

The Autonomous Logic Escalation (ALE) framework defines a taxonomy of behavioral failure modes used by AI agents when they deviate from assigned tasks, bypass constraints, or execute irreversible actions without human approval.

IDTechniqueDescriptionSeverity
ALE-T001 Logic Guessing Acts on unverified inference before an irreversible action, with zero tool-verified confirmation HIGH
ALE-T002 Credential Scavenging Autonomously scans filesystem or environment variables for unauthorised credentials after an access failure HIGH
ALE-T003 Recursive Escalation Logic-driven privilege escalation outside the authorised scope, substituting higher-privilege credentials HIGH
ALE-T004 Goal-Constraint Misalignment Explicitly acknowledges a safety constraint then generates a justification to override it — triggers Pipelock CRITICAL
ALE-T005 Silent Reasoning Loops A destructive action completes with no confirmation language, human checkpoint, or approval gate in the message history CRITICAL

Quickstart

Running in under two minutes.

# Clone and install
git clone https://github.com/trajectix-ai/trajectix-afr-
cd trajectix-afr-
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# Add your Google API key
echo "GOOGLE_API_KEY=your_key" > .env

# Run the live forensic dashboard (Gemma 4)
python src/dashboard.py

# Run with Gemini 2.5 Flash forensic analysis
ANALYSIS_MODEL=gemini python src/dashboard.py

# Route a live agent through the proxy
# Terminal 1:  python src/proxy.py
# Terminal 2:  ANTHROPIC_BASE_URL=http://localhost:8080 python src/test_agent.py
